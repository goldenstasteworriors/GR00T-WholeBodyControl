NaVILA: startup and output-only preview
Updated: 2026-11-03

Run each command as one line.
Do not manually wrap long lines.
Conversation language remains independent of these English files.

1. server02: Start inference

```bash
bash /home/user/ykj/project/NaVILA/deploy_server02/one_click.sh
```

2. Workstation: Start relay

```bash
bash /home/ykj/Desktop/navila_start.sh
```

3. ThinkPad: Open interface

```bash
bash /home/data-collection/GR00T-WholeBodyControl-worktrees/navila-g1-link/deploy/navila/start_thinkpad.sh --instruction "Walk to the table and stop in front of it."
```

The ThinkPad desktop also contains navila_start.sh.
Opening the interface does not initialize the robot.

4. ThinkPad menu: Preview saved image

```text
PREVIEW
```

Press Enter. No START or GO is required.
Default input: a previously saved G1 snapshot.
No controller, ROS motion publisher, or action execution is started.

5. ThinkPad menu: Preview live camera

```text
LIVE
```

Press Enter. The existing G1 camera must be available.
Only images are read; predicted actions are not executed.

6. Workstation: Preview directly

```bash
bash /home/ykj/Desktop/navila_preview.sh
```

7. Workstation: Preview live directly

```bash
bash /home/ykj/Desktop/navila_preview.sh --live --steps 20
```

8. ThinkPad: Preview directly

```bash
bash /home/data-collection/GR00T-WholeBodyControl-worktrees/navila-g1-link/deploy/navila/preview.sh
```

The ThinkPad desktop also contains navila_preview.sh.
Use --image /absolute/path/on/thinkpad.jpg for another image.
Use --instruction "Your English navigation instruction." to change the task.
Use --steps 0 to keep previewing until Ctrl+C.
The model and relay must already be running.
Raw responses are printed even when action parsing fails.
Look for "execute": false in each preview result.

REAL ROBOT CONTROL IS SEPARATE

9. Site: Connect and support G1

Connect G1 Ethernet to ThinkPad.
Power G1 and position the camera for navigation.

10. ThinkPad top-left menu: Press Enter once
This starts real joint initialization. Stay in the top-left menu.

11. Wait for ready in the Control pane

12. ThinkPad top-left menu: Press Enter again
This enables standing and starts navigation. No ] key or GO is required.

This executes predicted actions. The default budget is 20 actions.
Instruction used above:
Walk to the table and stop in front of it.

MANUAL ESTOP

14. Either menu: Request damping

```text
e
```

Press Enter. The Control pane also accepts d.
The workstation uses SSH; ThinkPad can request estop locally.
A damping acknowledgement is not measured physical standstill.

16. ThinkPad: Independent estop

```bash

```

The ThinkPad desktop also contains navila_estop.sh.

17. Either menu: Detach

```text
q
```

Detaching does not stop processes or request estop.
Rerun the startup command to return.
Click panes to focus; Ctrl+b then z toggles zoom.
Workstation p/l starts saved-image/live preview beside its estop menu.
Menus and existing sessions are reused without restarting active control.

Desktop files on both machines:
navila_start.sh
navila_estop.sh
navila_preview.sh
navila_quickstart.txt
navila_real_robot_test.txt

Preview never starts the robot controller. It does not stop another
controller that was already running independently.
No removed navigation watchdog or action cap has been reintroduced.

VISUAL LIVE PREVIEW (WORKSTATION)

Run this command on one line:

bash /home/ykj/Desktop/navila_viewer.sh

The browser opens http://127.0.0.1:8767 automatically.
Default task: Walk to the table and stop in front of it.
The page shows live video, the latest predicted command, raw response,
round-trip latency, and the last 20 predictions. No movement is executed.
Show model input switches to the latest image used for the completed prediction.
Keep the launch terminal open. Ctrl+C closes this preview only.
If already running, the command opens the existing preview and reports its task.
The model service and G1 camera must be online. The workstation relay is reused.

To stop the preview started by the assistant in tmux:

tmux send-keys -t navila-viewer:preview C-c

Passing --instruction updates the next launch even in an existing interface.
Omitting --instruction preserves the existing task. Running navigation keeps
its original instruction; a new task takes effect on the next GO.

EXIT AFTER FAILURE

In the ThinkPad top-left menu, type x and press Enter, or press Ctrl+C.
This interrupts navigation, camera and controller, then closes the interface.
The controller uses its original damping shutdown. Server and relay stay online.
q only detaches and leaves workers running. e requests damping ESTOP.

ThinkPad terminal, one line:

bash /home/data-collection/GR00T-WholeBodyControl-worktrees/navila-g1-link/deploy/navila/exit_thinkpad.sh

Workstation terminal, one line:

bash /home/ykj/Desktop/navila_exit.sh

If initialization exits, press Enter to retry after fixing the reported error.
If still initializing, wait for ready before pressing Enter to begin walking.
