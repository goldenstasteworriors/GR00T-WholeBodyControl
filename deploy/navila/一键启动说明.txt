
04【现场】接回机器人

网线接至ThinkPad。
机器人开机并支撑。

05【左上菜单】确认初始化

输入后回车：

```text
START
```

此步开始真实初始化。
控制器与相机启动。
不会自动使能站立。

06【右上控制】等待就绪

看到：

```text
ready
```

07【右上控制】启用站立

按键：

```text
]
```

08【左上菜单】确认导航

输入后回车：

```text
GO
```

默认最多20段。
英文任务如下：

```text
Find the beaker and stop in front of it.
```

09【两端菜单】阻尼急停

输入后回车：

```text
e
```

本机经SSH急停。
ThinkPad直接急停。
不经过server02。
控制窗也可按d。
回执不代表已静止。

10【本机】独立急停


11【ThinkPad】独立急停


12【两端菜单】脱离界面

```text
q
```
