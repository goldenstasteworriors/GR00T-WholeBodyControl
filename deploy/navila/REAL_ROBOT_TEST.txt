ONE-COMMAND INTERFACE
In the ThinkPad top-left menu: Enter 1 initializes, Enter 2 after ready
enables standing only, and Enter 3 after running starts navigation.
No Control-pane key is required. e+Enter requests ESTOP; x+Enter exits.
The numbered commands below are the manual terminal workflow.
Use English task instructions consistently.

Locations:
Workstation = local ykj computer
ThinkPad 1 = controller terminal
ThinkPad 2 = camera terminal
ThinkPad 3 = inference terminal
ThinkPad 4 = estop terminal
